# Getting started

Welcome to **Enriched Markdown**, a rich text solution built by [Software Mansion](https://swmansion.com).

It ships two components: `EnrichedMarkdownTextInput`, a rich text editor that styles text live as you type, and `EnrichedMarkdownText`, a read-only display component that renders rich text. Both are backed by native views on iOS, Android and macOS; the display also has a plain React/DOM build for the web. Both use **Markdown** as the layer underneath - the input produces it, the display consumes it.

Beyond the basic styles you already know, like **bold** or *italic*, the library provides more powerful tools such as a **native LaTeX renderer** - something you'll learn about later.

Enriched Markdown ships today as a React Native library, with standalone native SDKs on the way. The docs are organized around that split:

- **iOS** <ComingSoonBadge /> - a standalone SwiftUI view for native iOS apps, distributed as a Swift package.
- **[Rich text formatting](/rich-text-formatting/mentions)** - features that cut across the reference pages: mentions, LaTeX math, code-block highlighting, and Markdown streaming.
- **[User experience](/user-experience/accessibility)** - how the rendered text behaves for your readers: accessibility, RTL support, and copy options.

After that, work through the React Native section end-to-end - it takes you from an empty project to a working display and editor - and dip into Rich text formatting, User experience, and Misc as needed.
