# Getting started

Welcome to **Enriched Markdown**, a rich text solution built by [Software Mansion](https://swmansion.com).

It ships two fully native components: `EnrichedMarkdownTextInput`, a rich text editor that styles text live as you type, and `EnrichedMarkdownText`, a read-only display component that renders rich text. Both use **Markdown** as the layer underneath - the input produces it, the display consumes it.

Beyond the basic styles you already know, like **bold** or *italic*, the library provides more powerful tools such as a **native LaTeX renderer** - something you'll learn about later.

## How to navigate these docs

Enriched Markdown targets **iOS**, **Android**, and **React Native**, and the docs are organized around that split:

- **[React Native](/react-native/basics/installation)** - pick this section if you're building with React Native. It covers installation and the platform's SDK: the `EnrichedMarkdownText` display, the `EnrichedMarkdownTextInput` editor, style properties, and element structure. Start here.
- **iOS** and **Android** - native SDK docs are coming **soon**.
- **[Rich text formatting](/rich-text-formatting/markdown-flavors)** - cross-platform features like mentions, LaTeX math, code-block highlighting, and Markdown streaming.
- **[Misc](/misc/compatibility)** - supporting material: compatibility, macOS support, RTL, accessibility, and breaking changes.

If you're new, read the platform section for your target end-to-end — it takes you from an empty project to a working display and editor - then dip into Rich text formatting and Misc as needed.
