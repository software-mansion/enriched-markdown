# Compatibility

The table below shows which versions of `react-native-enriched-markdown`
support which React Native versions.

<EnrichedCompatibility />

The `nightly` row is the automated build published from `main` every day. It is
ahead of every numbered release, so treat it as a preview rather than a
supported version - see [Nightly builds](/react-native/basics/installation#nightly-builds).

## Platform requirements

The library also needs these minimum platform versions:

| Platform | Minimum |
| --- | --- |
| Android | `minSdk 24` (Android 7.0) |
| iOS | React Native's minimum deployment target; [`contextMenuItems`](/react-native/api-reference/enriched-markdown-text#contextmenuitems), `selectionMenuConfig` and `formatMenuConfig` additionally require iOS 16+ |
| macOS | 14.0, via [react-native-macos](https://github.com/microsoft/react-native-macos) |
| Web | Any browser with WebAssembly; MathML rendering for [LaTeX math](/rich-text-formatting/latex-math) needs Chrome 109+, Firefox, or Safari |

The React Native package also requires the [New Architecture (Fabric)](https://reactnative.dev/architecture/landing-page).

:::note
The macOS row is the deployment target, not a `react-native-macos` version. The
library's own macOS example app is built against `react-native-macos` 0.81,
which trails the React Native versions in the table above. See
[macOS support](/react-native/guides/macos).
:::

## Dependencies

| | |
| --- | --- |
| **Runtime dependencies** | None |
| **Peer dependencies** | `react`, `react-native` (no version floor declared beyond the table above) |
| **Optional peer dependency** | [`katex`](https://katex.org/) `>=0.16.0`, used only by the web build to typeset LaTeX |
| **Expo** | Supported through `npx expo install` and a [development build](https://docs.expo.dev/develop/development-builds/introduction/). The library's compile-time settings cannot apply in Expo Go. There is no config plugin - see [Installation](/react-native/basics/installation#expo). |
