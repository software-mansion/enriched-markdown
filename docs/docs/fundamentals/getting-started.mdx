# Getting started

The goal of *Fundamentals* section is to get you from an empty project to a working rich markdown **display** and/or **editor**. Additionaly at the end of this section we want you to have the mental model you need to incorporate into your own app. Let's jump in.

## Using the documentation
**Enriched Markdown** supports solutions for `ReactNative`, `Native iOS` and `Native Android`. To read documentation for specific version of the library, use the selector in the top right.

## What is <PlatformName /> Enriched Markdown?

<PlatformName /> Enriched Markdown is a **rich text solution** for <PlatformName /> <Platform only={["android","ios"]}> Native </Platform> built by [Software Mansion](https://swmansion.com).

It ships two fully native components: `EnrichedMarkdownTextInput`, a rich text editor that styles text live as you type, and `EnrichedMarkdownText`, a read-only display component that renders the rich text. Both use **Markdown** as a layer underneath - the input produces it, while the display consumes it.

Not only does this library allow you to apply basic rich text styles you know well, like **bold** or *italic*, but also provides more powerfull tools like **a native LaTeX renderrer**, something you will learn more about in the next chapters.

## Prerequisites

<Platform only="rn">
The library works only with the [React Native New Architecture (Fabric)](https://reactnative.dev/architecture/landing-page). It's enabled by default on recent React Native versions; if your app still runs the old architecture you'll need to switch before installing.

For the exact React Native versions we support, see [Compatibility](/misc/compatibility).
</Platform>
